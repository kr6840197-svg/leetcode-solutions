## Problem: Bubble Sort (Easy)

**Link:** N/A — Local implementation for the assignment

### Approach
I used the Bubble Sort technique by repeatedly comparing adjacent elements. If two adjacent elements are in the wrong order, they are swapped until the array is sorted.

### Complexity
- Time: O(n²)
- Space: O(1)

### Notes
The algorithm works directly on the original array without requiring extra space. An optimized version can stop early when no swaps occur during a pass.
